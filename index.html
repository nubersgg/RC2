How this works

A sandbox for planning Refinery Caves 2 logic builds and stress-testing them against server lag before you build them for real.
Editor
• Shift+A or "+ Add" opens a searchable component menu at your cursor — type to filter, then press Enter to place whatever's on top of the list without reaching for the mouse.
• Drag from an output port (right side dot) to an input port (left side dot) to wire them — multiple wires can land on the same port and OR together, just like wires colliding in-game. Keep holding Shift when you release to stay in wire-drawing mode: the very first port you grabbed stays the origin, so clicking more ports (or empty space) fans out a fresh wire from that same origin to each new target instead of chaining forward; let go of Shift or press Escape to stop.
• Double-click a wire (or right-click it → "Insert wire node here") to split it: a real Wire Node drops in at that spot and the wire is replaced by two wires running through it, exactly like a Blender reroute node — not a fake "bend point," an actual node you can select and G-move, and dragging a new wire out of it branches from that node itself. Right-click empty canvas → "Add wire node here" places one free-floating instead, ready to wire in from any direction.
• Right-click a wire → "Set wire color…" to give it (and its whole chain) a custom color: dim/dark-tinted while off, full brightness while on, same idea as every other on/off color pair in this sim. "Clear wire color" resets it back to the default blue/gray.
• A Wire Node is just a small dot, the same size as an old bend point. One with 2 OR MORE connections (a pass-through, or a branching junction) stays hidden until you select a wire it's on — click any part of that wire and the whole thing lights up together, branches included, all the way out to wherever it ends at a real component, since it's all really one continuous wire under the hood. A node with only 0 or 1 connection always stays visible. Click a visible node to select it, then G to move it; dragging directly on it always pulls a new wire out instead. Clicking a wire selects that whole wire (every branch, stopping only at real components), not just the segment under your cursor — shift-click another wire to add its whole wire to the selection too (shift-click an already-selected one again to remove just that one), so you can select and delete several separate wires at once. Deleting selected wire(s) acts on the whole thing — any Wire Node fully inside it (pass-through or junction) automatically reconnects around it where possible, so removing it never leaves a stray break behind. Deleting a real component with exactly one wire in and one wire out reconnects its two neighbors directly too, the same way.
• To delete just one branch instead of a whole wire: click a chain that's already selected (its highlight is already on) again — that "drills down" to select the exact segment under your cursor instead of the whole thing (its own highlight replaces the chain-wide one so you can see exactly what's picked), and Delete/X now removes only that segment, leaving every other branch and Wire Node exactly where it is. Click that same segment again to zoom back out to the whole chain, or click elsewhere to start fresh. Right-click a wire → "Delete this segment only" does the same thing in one step, no drilling required.
• Hold Ctrl to preview the custom grid (scroll while held to resize it) — dragging anything while Ctrl is held locks it to that grid instead of the normal smart alignment. Keep scrolling down past the smallest spacing and the grid switches fully off: no background lines at all, no grid rounding on ordinary drags either, so everything can be placed completely freely. Scroll up once to bring it straight back.
• The bar along the bottom of the canvas is context-sensitive — it always lists only the keys that apply right now, and rewrites itself the moment you hold Ctrl/Shift/Alt, start a wire, grab something with G, or select a wire vs. a component.
• Smart alignment works port-to-port, not just edge-to-edge. Every individual port on the part you're dragging is its own snap point, so you can line an output up exactly with the input it feeds — including on parts with TWO outputs (Latch Q/¬Q, Toggle Q/¬Q, Button Double), where neither output sits on the node's centreline and centre-based snapping could never reach them. Guides are colour-coded so you can see what caught: cyan = port-to-port (thick when it's an output feeding an input, the case you usually want), yellow = plain edge/centre, green = centred between two neighbours, purple = matched the spacing rhythm two other parts already use (the gap is labelled). Drop a third identical gate past two evenly-spaced ones and it snaps to that same gap; drop one between two others and it centres with equal gaps either side. Parts of the same type as the one you're dragging are preferred when deciding which rhythm to follow. Hold Ctrl at any time to bypass all of it.
• Only components with real modes/settings show a gear icon in their header — click it (or double-click the component) to configure.
• Drag a box around nodes then Ctrl+G to group them; double-click a group's title bar to rename it; click/drag anywhere inside a group's rectangle to move the whole thing; adding a component while a group is selected drops it inside that group.
• X, Delete, or Backspace deletes the current selection. Ctrl+Z undoes the last edit, Ctrl+Y redoes it (undo history is per-tab and doesn't cover the running simulation itself — just circuit edits).
• Click Lever/Button/Switch bodies to trigger them while the sim is running.
• Use the ◀ ▶ tabs on the canvas edges to hide the side panels; use the tab strip at the top to keep several circuits open and switch between them.
• The left sidebar groups components into colored, collapsible categories — click a category to open it, which closes whichever one was open before, so the list stays short instead of scrolling through everything at once.
• Mark a tab as a Function (click its ƒ chip) to turn it into a placeable, reusable component everywhere else. Function Input/Output define its ports; a Bool Display or Number Display placed anywhere inside that same tab also mirrors its live reading (colored ON/OFF text, or a live number) onto the outer Function's own card, so you can tell what it's doing without opening the tab. Double-click a placed Function to jump straight into its source tab.
• Zoom out far enough and components switch to compact icons so the canvas stays readable.

World / Lag tab
Real RC2 servers don't evaluate logic at a perfectly smooth rate — under load, the gap between server updates stretches and gets spiky. Any signal that turns on and back off entirely inside one of those gaps (a Button's 1s pulse, a Blink Circuit's short pulse, a Repeat Circuit toggling fast) can be sampled as if it never happened. That's the "pulse eaten by lag" bug the wiki itself warns about for Blink Circuits.

Drag the single Server Strain slider (or open Advanced for the individual knobs), hit Run, and watch the event log flag exactly which pulses got swallowed — then redesign (e.g. add a Pink Delay Circuit after a Blink to stretch the pulse) and re-test. The same tab also has the day/night clock — scrub the time of day or set a cycle speed for testing Day/Night Sensors.
